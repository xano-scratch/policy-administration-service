Policy Administration Service

A governed insurance policy lifecycle in one Xano API layer. Quote, bind, endorse, renew, and cancel are an enforced state machine. The premium is recomputed on every change, and every change is written to a readable history.

What it demonstrates

The kind of service a legacy admin monolith holds today, rebuilt as one Xano backend a team can read and trust.

A real state machine

Status moves quoted, bound, active, renewed, cancelled. Illegal moves are refused at the API layer, not applied.

Derived logic in one place

The base premium is computed from the coverages. An endorsement recomputes it and records the value before and after.

API-layer RBAC

Agents quote, underwriters bind and endorse, viewers read. Each endpoint re-reads the caller's live role. Never row-level security.

An append-only audit trail

Every transition and every premium change writes an event, so the full story of a policy reads in order.

API surface

Nine endpoints across three groups. Each one enforces a rule a human would want to audit.

VerbPathWhat it enforces
POST/api:auth/loginChecks the password, mints a role-carrying token
POST/api:policy/quoteAgent or underwriter, needs a coverage, computes the base premium
POST/api:policy/bindUnderwriter, only a quoted policy, stamps the term dates
POST/api:policy/endorseUnderwriter, only an active policy, recomputes the premium
POST/api:policy/renewUnderwriter, active and in its renewal window, rolls the term forward
POST/api:policy/cancelUnderwriter, not already cancelled, records the reason
GET/api:policy/get/{policy_id}Any role, the policy with coverages, endorsements, and history
GET/api:policy/listAny role, policies with status and premium, filterable
POST/api:seed/runLoads the demo book, ephemeral only

The screens

A React and Vite frontend that derives its paths and types from the backend defs.

  • Login and role switcher. Sign in as an agent, underwriter, or viewer, and see which actions the role unlocks.
  • Policy list. Status badges and current premium, filter by status, start a new quote.
  • Quote and bind. Enter a policyholder and coverages, watch the base premium estimate, then bind.
  • Policy detail. Coverages, the current premium, an endorsement form with an inline recompute, renew and cancel, and a history timeline.
